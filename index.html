မြန်မာဘာသာပြန် • Recap Script • စာတန်းထိုး • မြန်မာအသံ • MP4 Export

ဒီဟာက ကိုယ်ပိုင် Movie Recap Website ရဲ့ စတင်အသုံးပြုနိုင်တဲ့ UI နမူနာဖြစ်ပါတယ်။ AI ဘာသာပြန်၊ AI အသံနဲ့ MP4 ပေါင်းစပ်မှုတွေကို တကယ်အလုပ်လုပ်စေဖို့ နောက်တစ်ဆင့်မှာ backend/API ချိတ်ဆက်ရပါမယ်။

STEP 01

ရုပ်ရှင်ဖိုင် ရွေးချယ်ရန်

ဖိုင်ကို browser ထဲမှာသာ ရွေးချယ်ထားမည်။ ဒီ starter က server သို့ upload မလုပ်သေးပါ။

STEP 02

မြန်မာ Recap ဇာတ်ညွှန်း

AI ဘာသာပြန်ခလုတ်ကို အမှန်တကယ်လုပ်ဆောင်စေဖို့ လုံခြုံတဲ့ backend နဲ့ AI API ချိတ်ဆက်ဖို့ လိုပါတယ်။ API key ကို ဒီ HTML ထဲမှာ မထည့်ပါနဲ့။
STEP 03

မြန်မာစာတန်းထိုး (SRT)

စာကြောင်းတစ်ကြောင်းစီကို အချိန်တစ်ခုစီ သတ်မှတ်ပေးနိုင်ပါတယ်။ ဒီနမူနာက auto-sync မလုပ်သေးပါ။

အဆင်သင့်ပါပြီ။
STEP 04

MP4 Export

MP4 အပြီးသတ်ထုတ်ဖို့ ဗီဒီယို၊ အသံ၊ စာတန်းတွေကို FFmpeg လို video-processing engine နဲ့ backend ပေါ်မှာ ပေါင်းစပ်ရပါမယ်။ ဖုန်း browser ထဲက ဒီနမူနာတစ်ခုတည်းနဲ့ အဲဒီအလုပ်ကို မလုပ်သေးပါ။

အသုံးပြုခွင့်ရှိသော ဗီဒီယိုများကိုသာ အသုံးပြုပါ။ မူပိုင်ခွင့်ရှိသော ရုပ်ရှင်များကို ပြန်လည်အသုံးပြုခြင်းအတွက် ခွင့်ပြုချက်နှင့် သက်ဆိုင်ရာစည်းမျဉ်းများကို စစ်ဆေးပါ။
